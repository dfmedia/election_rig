# Design

Starts after the Align phase defines the workflow. Expected contents:

- `workflow/` — current-state workflow map (from interviews and the timed walkthrough) and target-state workflow.
- `admin/` — newsroom admin UI: AP import, race list, Collections, overrides and race calls, test mode, print export.
- `reader/` — results displays: race charts, Collections, maps (open question), app embeds and home-screen widgets, print/agate.
- `prototypes/` — links to Figma and prototype tests.

Design system references: MNG Web Design System (`dfmedia/mng_web_ds`) and the app design systems (`mng_apps_*_ds`).

Big open design question: **maps.** Which map levels editors need on election night and readers use, where boundary files come from, and whether a ranked table serves some races better. See "The maps problem" in the project brief.
